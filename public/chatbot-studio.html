Overview

오늘 완성하는 것 — 학과 챗봇 2종

60분 기초 실습이 "채팅 한 번 해보기"였다면, 이번 심화 실습은 우리 학과 사무실이 실제로 배포할 수 있는 챗봇을 두 가지 방식으로 직접 만들어보는 시간입니다.

실습① 단일 챗봇 실용무용과 학과 사무실이 신입생 문의에 답하는 FAQ 챗봇. 프로필·동작·지식·공유 4단계로 완성합니다.
실습② 워크플로우 챗봇 입학홍보처가 재학생 문의와 입시 문의를 자동으로 분류해 서로 다른 담당 에이전트로 연결하는 라우팅 챗봇입니다.

Practice 01 · Single Chatbot

🧩 단일 챗봇 만들기 — 실용무용과 학과 FAQ 안내 챗봇

스튜디오에서 새 챗봇을 만들면 순서대로 나타나는 4개 탭 — 프로필 → 동작 → 지식 → 공유 — 을 그대로 따라가면 완성됩니다.

  1. 1

    👤 프로필 탭 챗봇의 얼굴

    챗봇 이름과 소개, 첫 화면에 보여줄 추천 질문 3가지를 정합니다.

    준비물

    학과명, 한 줄 소개, 신입생이 자주 묻는 질문 3가지

    실행 스크립트

    프로필 탭 열기 → 이름 "실용무용과 도우미" 입력 → 소개문 2~3문장 작성 → 추천 질문 3개 등록

    결과물

    챗봇 프로필 카드 완성

  2. 2

    ⚙️ 동작 탭 챗봇의 두뇌

    모델을 고르고, 챗봇이 어떻게 답할지 정하는 시스템 프롬프트를 입력합니다.

    준비물

    텍스트 모델 1개 선택(GPT·Claude 등), 아래 프롬프트

    실행 스크립트

    동작 탭 → 모델 선택 → 프롬프트 입력창에 아래 프롬프트 붙여넣기 → 저장

    결과물

    테스트 대화 통과

    바로 쓰는 프롬프트 · 동작 탭
    당신은 대경대학교 실용무용과 학과 안내 챗봇입니다. 등록된 학과 자료만 근거로 짧고 정확하게 답하세요.

응답 원칙:
1. 결론을 먼저 말하고 필요한 절차를 번호로 안내
2. 날짜·연락처·자격 조건은 근거 문서명과 함께 제시
3. 자료에 없는 내용은 추측하지 말고 "학과 사무실 확인이 필요합니다"라고 안내
4. 학번·전화번호 등 개인정보를 요청하거나 노출하지 않기
5. 실습실 안전사고 등 위험 관련 질문은 안전 안내를 최우선으로 답변
6. 답변 끝에 사용자가 이어서 물어볼 만한 질문 2개 제안
  3. 3

    📚 지식 탭 챗봇의 근거

    학과 자료를 첨부해 챗봇이 실제 문서를 근거로 답하게 만듭니다.

    준비물

    아래 다운로드 자료의 학과 FAQ 지식베이스 PDF

    실행 스크립트

    지식 탭 → 파일 첨부 → 지식베이스 PDF 업로드 → 테스트 질문 3개로 근거 인용 확인

    결과물

    근거 문서 기반 자동 응답

  4. 4

    🔗 공유 탭 챗봇의 배포

    누가 수정할 수 있고, 누가 사용만 할 수 있는지 정한 뒤 배포합니다.

    준비물

    배포 대상 목록(신입생·재학생·조교), 공지 문구

    실행 스크립트

    공유 탭 → 편집자/뷰어 권한 설정 → 학과 챗봇 스토어에 게시 → 학과 SNS·게시판에 링크 공지

Practice 02 · Workflow Chatbot

🔀 워크플로우 챗봇 만들기 — 입학홍보처 통합 안내 라우팅

재학생 문의와 입시 문의가 한 창구로 몰릴 때, 노드를 연결해 자동으로 담당 에이전트에게 나눠주는 워크플로우입니다. Start → Guardrail → Classify → Agent A / Agent B → End 순서로 만듭니다.

▶ Start첫 인사말
→
🛡 Guardrail개인정보·금칙어 차단
→
🔎 Classify문의 유형 분류
→
🧑‍🎓 Agent A재학생 학사팀
🎓 Agent B입시 홍보팀
→
■ End마무리 안내

▶ Start 노드

첫 인사말로 재학생인지 입시 준비생인지 자연스럽게 확인합니다.

Start 인사말 예시
안녕하세요! 대경대학교 통합 안내 챗봇입니다 🎓
재학 중이신가요, 아니면 입학을 준비 중이신가요? 편하게 질문해주시면 담당 팀으로 바로 연결해드릴게요.

🛡 Guardrail 노드 — 개인정보·금칙어 차단

분류에 앞서 위험한 입력을 먼저 걸러냅니다. 이 노드를 설정하지 않으면 저장할 수 없습니다.

Guardrail 규칙
다음 조건에서는 답변을 즉시 중단하고 안내 문구로 대체하세요.

1. 학번, 전화번호, 주민등록번호 등 개인정보가 포함된 입력은 마스킹 처리 후 진행
2. 욕설·비방·차별적 표현이 포함되면 응답을 생성하지 말고 "부적절한 표현으로 응답이 제한됩니다"라고 안내
3. 입시 합격 여부·성적 등 확정되지 않은 개인별 결과는 예측하거나 단정하지 않기

🔎 Classify 노드 — 문의 유형 분류

저비용·고속 모델로 문의를 두 갈래로 분류한 뒤 해당 에이전트로 라우팅합니다.

Classify 프롬프트
사용자 문의를 다음 두 카테고리 중 하나로 분류하세요.

- A: 재학생 학사 문의 (수강신청, 성적, 장학금, 시설이용 등)
- B: 입시 문의 (전형일정, 실기고사, 지원자격, 모집요강 등)

분류가 애매하면 임의로 정하지 말고 "재학생이신가요, 입학을 준비 중이신가요?"라고 되물어 확인한 뒤 분류하세요.

🧑‍🎓 Agent A 노드 — 재학생 학사팀

학사일정.pdf · 교과과정.pdf · 시설·장학금.pdf 3개 문서를 첨부하고 아래 프롬프트를 입력합니다. 모두 대경대학교 공식 홈페이지 게시 내용을 발췌한 실제 자료입니다.

Agent A 프롬프트
당신은 대경대학교 재학생 학사 안내 담당입니다. 첨부된 학사일정·교과과정·시설·장학금 문서만 근거로 답하세요.

1. 결론 먼저, 필요한 절차는 번호로 안내
2. 학과별로 내용이 다를 수 있으니 어느 학과인지 확인 후 답변
3. 문서에 없는 내용은 "교학팀 확인이 필요합니다"로 안내
4. 답변 끝에 담당 부서 연락처 안내

🎓 Agent B 노드 — 입시 홍보팀

입학전형.pdf 문서를 첨부하고 아래 프롬프트를 입력합니다. 대경대학교 입학정보 공식 홈페이지(dkuway.com)의 실제 전형일정을 발췌한 자료입니다.

Agent B 프롬프트
당신은 대경대학교 입학홍보처 상담 담당입니다. 첨부된 입학전형 문서만 근거로 답하세요.

1. 전형별 일정·전형요소를 표로 정리하듯 이해하기 쉽게 안내
2. 합격 가능성, 실기 점수 등 개인별 결과는 절대 예측하지 않기
3. 최신 정보 확인이 필요하면 "입학홍보처 공식 홈페이지 확인 필요"로 안내
4. 답변 끝에 입학상담 신청 방법 안내

✅ 저장 전 검증 체크리스트

아래 조건을 모두 확인해야 저장·배포할 수 있습니다.

  • Guardrail 노드가 Classify보다 먼저 실행되는지 확인
