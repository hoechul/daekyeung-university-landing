# 대경대학교 교직원 팩트챗(FactChat) 실습 교육 랜딩페이지

공연·예술 특화대학 대경대학교(경산) 교직원을 위한 60분 실습형 AI(팩트챗) 활용 교육 랜딩페이지입니다.
대학의 상징색인 보라색(설립자 도전정신·창의성)과 왕관(Crown) 심볼을 모티프로, 무대 커튼·스포트라이트
느낌의 다크 퍼플 + 골드 톤으로 디자인했습니다.

- 60분 · 6개 세션 × 10분 실습 커리큘럼 (채팅 → 챗봇비교 → 자료정리 → **이미지생성** → **영상생성** → 챗봇스튜디오)
- 공연예술 특화 학과(실용무용과·특수분장예술과·연기예술과·국제태권도과·K-모델연기과 등) 실무 예시 반영
- 이미지 생성 · 영상 생성 실습 사례 각 4종, 프롬프트 복사 버튼 포함

## 개발 서버 실행

```bash
npm run dev
```

> **참고**: 이 저장소 경로에 한글 폴더명이 포함되어 있어 Next.js 16의 기본 번들러인 Turbopack에서
> 알려진 인코딩 버그(panic)가 발생합니다. 이를 피하기 위해 `dev`/`build` 스크립트에 `--webpack`
> 옵션을 고정해두었습니다. (Vercel 등 한글이 없는 경로에 배포할 때는 문제가 재현되지 않습니다.)

## 배포

Vercel에 배포하려면:

```bash
npm i -g vercel   # 최초 1회
vercel            # 프리뷰 배포
vercel --prod     # 프로덕션 배포
```
